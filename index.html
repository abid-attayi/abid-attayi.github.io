Featured project

An RTOS kernel, from scratch.

A pre-emptive multithreading kernel in C on an STM32 (ARM Cortex-M4). Written solo. It is not a port of an existing RTOS.

01 · SysTick

It starts with a 1 ms tick.

SysTick fires every millisecond and counts down the running thread's time budget. That tick is the kernel's clock.

02 · PendSV

Time's up. Swap.

When the budget hits zero the kernel pends PendSV, which saves the outgoing thread's registers and stack pointer.

03 · Scheduler

Round-robin picks who's next.

The scheduler advances to the next thread and reloads its timeslice. Up to 16 threads, each with a 1 KB stack carved from a 16 KB pool.

04 · SVC

System calls stay safe.

Calls go through SVC, which outranks PendSV, so a call is never interrupted mid-switch. Cooperative and pre-emptive threads run side by side.
